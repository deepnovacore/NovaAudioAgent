# Loop Camera：视觉监控

Loop Camera用一个独立的视觉模型观察摄像头，并按你设定的条件上报。前台对话照常进行，所用模型无需支持图像输入。

## 使用方式

在桌面设置中选择监控摄像头和模型，授予摄像头权限，然后描述条件，例如“看着这个画面，有人出现就告诉我”。任务期间设备固定不变，结束监控即释放摄像头。

## 运行时行为

| 项目 | 当前行为 |
|---|---|
| 并发 | 同一时间只有一个监控任务 |
| 默认采样 | 每 2.5 秒一次；处理慢不会积压待处理画面 |
| 默认时长 | 30 分钟 |
| 条件命中 | 上报一次后继续运行；连续两次未命中后重新允许上报 |
| 连续失败 | 采集或推理连续失败三次后结束 |
| 停止或超时 | 先取消采集与推理，再释放摄像头 |

内置摄像头和 USB 摄像头按设备 ID 选择。已选设备断开后不会自动换用其他摄像头。网络摄像头、RTSP、手机摄像头以及连续视频上下文目前均不支持。

## 与对话视觉的区别

对话视觉从默认摄像头抓取一帧，服务于提交的转录或文本轮次。Loop Camera 有自己的任务、设备、采样间隔和模型。图像和观察结果仅为证据；画面中出现的文字不能用于授权操作。

模型选择见[支持矩阵](../support-matrix.md)，实现细节见[原生视觉与独立监控](../archs/11-vision.md)。
