# 模型上下文

`ContextView` 是运行时为一次模型调用整理的上下文快照，包含近期对话、相关通道的证据、正在执行的任务、候选建议和结构化结果。它有明确的范围限制，不会把全部记忆直接交给模型。

授权和项目确认状态由宿主程序单独管理。知识检索结果只供模型参考，不能成为执行操作的授权。

<a id="realtime-delivery-truth"></a>
## 把当前项目同步给实时模型

`RealtimeAssembly.#injectCurrentProjectContext` 通过两个区块提供当前状态：

- `<active_project_context>`：当前项目的显示名称和会话标题。
- `<active_executor_context>`：当前正在进行的工作。

宿主一次性提供工作区身份和对应的显示信息，避免两者不一致。上下文不包含项目列表，也不带入其他工作区的内容。内容变更会推进修订号；模型服务重连后，宿主重新发送当前状态。

## 更新时替换旧内容

`workspace_context` 只能用于宿主注入上下文，不能被解释为宿主操作或新的用户输入。适配器必须具备经过验证的替换或刷新能力，才能发送这类内容。

Qwen 的替换流程分两步：先确认删除旧条目，再单独确认创建新条目，避免旧项目上下文不断累积。必须发布的项目上下文尚未送达时，执行器不能提前启动；会话身份和修订号检查会拒绝过期的投递。

项目确认与执行的边界见[执行器](05-executors.md)。
