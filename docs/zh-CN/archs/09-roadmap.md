# 路线图

Nova 已提供实时对话、后台执行、视觉监控、个人记忆、知识库和 iPhone 客户端。Workbench 主窗口运行一套持久化的任务循环，支持验收标准与接管/交还，并让个人记忆与主动建议基于你授权的信息来源与连接器。当前兼容范围见[支持矩阵](../support-matrix.md)。

接下来主要探索三个方向：

- **更多编码后端。** 在 Codex 之外接入 Kimi Code、pi agent，复用项目管理、审批、进度和取消机制。
- **GUI-use。** 将图形界面任务交给专门的智能体，明确设备选择、操作权限和执行结果。
- **更多连接器。** 在现有的 Google、macOS 日历/邮件与飞书之外，接入更多只读账号与服务。

以上是规划方向，不代表已经支持，也不构成发布时间承诺。各后端的兼容范围会单独说明。
