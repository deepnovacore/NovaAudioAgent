# 资料来源与连接器

小诺只读取你明确连接的资料——本地文件夹、邮件与日历，还有飞书会话——并且只有在你另外同意之后，才会把这些内容交给模型处理。

## 连接、同意处理、暂停、断开、删除

| 操作 | 作用 |
|---|---|
| 连接 | 授予访问权限：一个文件夹、一个账号，或者一批会话 |
| 同意处理 | 单独的开关，允许配置好的模型服务读取内容；连接了资料不代表已经同意 |
| 暂停 | 保留连接和已经收集的内容，只是不再读取新的 |
| 断开 | 停止在本机收集，但保留已收集的数据（飞书还会保留应用配置）。对通过 Composio 连接的服务，这不会撤销你给出的 OAuth 授权，需要的话请到 Composio 或对应服务里单独撤销 |
| 删除历史 / 本地数据 | 清除已收集的内容，这是独立于断开连接的另一步操作 |

## 本机文件

在设置的「本机资料」标签页里，必须先勾选同意，才能使用「选择文件夹」或「授权所有可访问的本机文件」。每个来源每轮同步最多读取 1 到 200 个文件、合计不超过 20 MB；超出的部分会顺延到之后的同步里，并不是累计上限。支持的类型包括纯文本、Markdown、JSON、YAML、CSV、常见源代码后缀、PDF 以及 Word（`.docx`）。

版本控制、构建产物、依赖和缓存目录，以及浏览器的配置目录，会被自动排除。隐藏文件和隐藏目录默认跳过，除非你按名字单独选中；项目本身在 Git 里忽略的内容同样会跳过。全盘授权模式还会排除系统和应用程序目录，依然遵守操作系统的文件权限，分批处理，暂停后立刻停止读取。

## 邮件与日历

| 来源 | 扫描范围 | 每轮检查量 | 保留时长 |
|---|---|---|---|
| macOS 邮件 | 最近最多 180 天 | 最多 500 封 | 收到后保留 180 天 |
| macOS 日历 | — | 每页最多 200 个事件 | 事件结束后保留 30 天 |
| Composio Gmail | 自上次同步起，首次为快照 | 每页最多 200 条待处理变更、8 封正文 | 邮件时间起保留 30 天 |
| Composio 日历 | 一段可配置的前后天数窗口 | — | 事件结束后保留 30 天 |

macOS 邮件与日历直接使用你 Mac 上已有的系统应用。Composio 通过自己的 OAuth 流程在任意平台上连接 Google 邮件和日历，并限制单台主机最多同时保留 20 个来源连接。较长的正文会被截断（约 99000 字符），并附一句提示告诉你去哪里看完整内容。

## 飞书

飞书接入用的是你自己的飞书应用，通过 `lark-cli` 完成——没有内置应用，也不共享任何凭证。连接器要求 `lark-cli` 版本不低于 1.0.69，版本过旧会直接拒绝。

1. **连接应用**——在飞书官方开发者页面新建一个，或者绑定已有的应用，填入 App ID 和 Secret。Secret 只通过标准输入传递，绝不会作为命令行参数出现；已经绑定过的应用不会被静默替换。
2. **登录账号**，走一遍 OAuth 的设备码授权流程。
3. **选择会话**——按真实名称挑选要同步的会话，没有预设分类。

需要的权限包括读取会话列表、读取消息、读取消息表情回应，以及 OAuth 的离线访问权限。首次同步覆盖最近 7 天，之后从上次的位置继续。文本和富文本消息会被保存；不下载附件，只会显示一条提示。只记录真人发的消息，机器人自己发的消息不会被重复收录。消息内容保留 30 天。

机器人提醒是可选开启的功能，只会发到你和机器人的私聊，不会发到群里。提醒卡片可以打开、稍后提醒或忽略；打开卡片只是跳转到小诺，不代表授权它执行任何操作。凭证保存在独立目录里，和其他应用的登录信息互不共享。

断开连接会清除登录状态，但保留应用配置和历史记录；删除历史会清除已收集的消息以及由它们生成的记忆，这是独立于断开连接的另一步；之后重新连接会从头开始新一轮收集。
