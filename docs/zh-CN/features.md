# 功能概览

Nova 是运行在电脑上的语音助手。你可以直接交办编码任务、追问进度、搜索信息，并通过 iPhone 连接电脑继续使用。

## 对话与任务

| 能力 | 使用方式 |
|---|---|
| 实时语音 | 直接说出需求，也可以在 Nova 说话时打断 |
| 编码任务 | 描述目标，回答必要的追问，再由 Codex 执行 |
| 项目与会话 | 创建或切换项目，在已有会话中继续工作 |
| 进度反馈 | 查看任务横幅、进度气泡和对话记录 |
| 权限确认 | 遇到需要授权的操作时，在界面确认或拒绝 |

切换项目或创建项目需要确认。识别失败不会被当作同意、拒绝或取消任务；断开手机连接也不会自动取消电脑上的编码任务。

## Workbench

- **Workbench** 是桌面主窗口：图标导航栏包含 Todos、Ideas、Goals、Feeds、Tasks 和 Profile，右侧是可收起的对话栏。详见[Workbench](workbench.md)。
- **Tasks** 用于委派工作，你可以设定验收标准；随时查看进度，也可以接管任务直接指挥执行器，完成后交还给 Nova。详见[Tasks](tasks.md)。
- **Todos、Ideas、Goals** 收集 Nova 在对话中留意到的内容：你明确说出的待办会直接记下，并可以撤销；其余候选需要你确认、编辑或跳过。
- **Profile** 保存关于你的信息，包含个人记忆视图。
- **Feeds** 展示按你的兴趣整理的资讯流。
- 项目页面提供概览卡片，汇总最近的活动。
- **信息来源与连接器**让建议和记忆基于你授权的账号与文件。详见[信息来源与连接器](sources-and-connectors.md)。
- **声纹校验**可以将语音指令限定给已注册的说话人。

## 信息与记忆

- **搜索**：使用配置的搜索服务查找信息。
- **个人记忆**：从对话中整理信息，供后续会话查询；默认保存在本地统一记忆账本中，也可显式选择 mem0。
- **文档知识库**：导入文件后检索其中的内容，与个人记忆分别管理。
- **外部工具**：通过 MCP 连接已配置的服务，只开放你选择的工具。

## 语音、视觉与手机

默认使用 Qwen 实时语音。也可选择级联模式，分别配置语音识别、语言模型和语音合成。

对话视觉默认关闭，需选择支持图像的级联模型后开启。独立监控可按指定条件观察摄像头画面。相机权限和设备可用性会影响这两项功能。

本地唤醒词默认关闭；开启后，悬浮球待机时可以通过唤醒词恢复。主动静音后，需要手动解除静音。

iPhone 默认显示实时对话。连接支持可编辑输入的级联服务时，可以切换文字聊天或使用听写草稿。手机上的消息列表不保证在应用重启后保留。

## 使用限制

- 编码需要电脑上可用且已登录的 Codex；模型、搜索等服务需要相应凭据。
- 本地记忆和知识库仍可能调用远程模型处理文本。
- 默认记忆账本的查看页支持纠正与忘记条目；mem0 查看页暂不提供这些功能。
- 手机使用依赖电脑服务在线及网络可达，不支持手机摄像头和后台唤醒词。
- 桌面支持 macOS arm64、Windows x64 和 Ubuntu 22.04+ x64。
