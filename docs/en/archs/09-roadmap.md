# Roadmap

Nova currently combines real-time conversation with background execution, camera monitoring, personal memory, document knowledge and an iPhone client. The Workbench main window runs a durable task loop with acceptance criteria and take-over/hand-back, and grounds personal memory and proactive suggestions in the sources and connectors you authorize. See the [support matrix](../support-matrix.md) for current compatibility.

The next directions are:

- **More coding backends.** Add Kimi Code and pi agent adapters alongside Codex, reusing project management, approvals, progress and cancellation.
- **GUI-use.** Delegate graphical-interface tasks to a specialized agent, with explicit device selection, permissions and observable results.
- **Broader connectors.** Extend beyond the current Google, macOS Calendar/Mail and Feishu sources to more read-only accounts and services.

These are planned directions, not currently supported integrations or release-date commitments. Each backend will have its own compatibility requirements.
