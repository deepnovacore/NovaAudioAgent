# 8. Deferred Work

The project intentionally defers:

- a universal workflow or graph language;
- unrestricted long-term memory search;
- cross-executor transactions without a concrete shared-resource case;
- multiple simultaneous speaking personas;
- automatic privilege expansion for device or code executors;
- provider-specific state as canonical memory.

Each item should return only with a concrete use case that cannot fit the current port and lifecycle
contracts. Deferral keeps speculative machinery out of the core.
